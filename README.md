||Sistema de Gestión de Infraestructura Ferroviaria Urbana||

    Descripción del Proyecto: El proyecto nace de la necesidad de coordinar múltiples variables críticas en tiempo real, desde el estado de las unidades de transporte hasta la programación de horarios y la gestión del talento humano.

    Tecnologias Usadas:

        BackEnd:
            Java 17: El lenguaje base
            Spring Boot: Framework base para la creación de API y la logica del negocio
            Spring Data JPA: Para la gestión y consultas a la base de datos

        Frontend:
            Thymeleaf: Motor para renderizar el contenido dinamico
            HTML 5 y CSS3: Estructura y estilo
            JavaScript: Para animaciones

        Base de Datos:
            MySQL: Motor de base de datos

    Caracteristicas:
        Diseño Responsivo
        Experiencia de Usuario
